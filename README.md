# 文研 · 文学考研助手

面向中国语言文学考研的轻量学习工具，纯前端实现，**无需安装、无需后端、无需构建**，浏览器打开 `index.html` 即可使用。

## ✨ 功能

- **📚 知识点浏览** — 涵盖中国古代文学、现当代文学、外国文学、文学理论四大板块，支持分类筛选与关键词搜索，点击卡片查看详细解析。
- **✍️ 真题练习** — 按科目与题量组卷，在线作答、自动判分，交卷后查看错题与解析。
- **🗂️ 记忆卡片** — 名词解释翻转卡片，基于简化艾宾浩斯记忆法标记掌握程度，进度自动保存在本地。
- **📊 进度统计** — 累计答题数、背诵数本地持久化，可一键重置。

## 🚀 使用方法

### 方式一：直接打开
下载本项目，用浏览器打开 `index.html` 即可。

### 方式二：本地启动（推荐）
```bash
# 任选一种方式启动静态服务
python3 -m http.server 8000
# 或
npx serve .
```
然后访问 `http://localhost:8000`。

## 📝 扩充题库

所有数据集中在 [js/data.js](js/data.js)，按既有结构添加即可：

```js
// 新增知识点
{ id: "k-xx", subject: "ancient", title: "标题", summary: "摘要",
  sections: [{ h: "小标题", p: "段落" }] }

// 新增选择题
{ id: "q-xx", subject: "ancient", stem: "题干",
  options: ["A","B","C","D"], answer: 0, explain: "解析" }

// 新增记忆卡片
{ id: "c-xx", subject: "ancient", term: "名词", def: "释义" }
```

`subject` 取值：`ancient`（古代）/ `modern`（现当代）/ `foreign`（外国）/ `theory`（理论）。

原生 HTML / CSS / JavaScript，零依赖、零构建。数据通过 `localStorage` 持久化，所有内容离线可用。
