# 文研 · 个人文学考研训练器

> 只服务一个人：围绕南京师范大学文学考研，做一个能每天真正拿来复习、答题和写作训练的小工具。

这个仓库正在从早期的“文学知识浏览 Demo”重构为一个 **单人、小而美、开发快、维护轻、不过度工程化** 的个人考研工具。

## 现在最重要的目标

文研不追求功能大而全，也不追求成为通用学习平台。

它只回答三件事：

1. **我今天该学什么？**
2. **这个知识点我到底记住没有？**
3. **遇到真题，我能不能把它答出来、写出来？**

核心学习闭环：

**今日计划 → 主动回忆 → 真题/论述输出 → 发现漏点 → 回到知识点 → 再复习**

## 开发原则

- **个人使用优先**：不为了“未来可能有很多用户”预先设计复杂系统。
- **开发效率优先**：能用简单代码解决，就不引入框架、服务和抽象层。
- **先好用，再完美**：允许适度重复，允许以后再重构；不为了工程洁癖拖慢可用版本。
- **学习收益优先**：不能明显帮助记忆、答题、写作的功能先不做。
- **内容与程序分开**：知识点、真题、论述资料尽量保持独立数据，方便持续整理。
- **本地优先**：操作先写本地、界面立即响应；跨设备状态同步只做薄层，不重建复杂后端。
- **AI 是编辑和辅助，不是知识来源**：核心内容必须能追到可靠教材、公开课程、原典或真题。

## 技术方向

当前仍坚持极轻量路线：

- 原生 HTML
- 原生 CSS
- Vanilla JavaScript
- 浏览器本地存储
- 静态部署

除非真实使用中出现明确需求，否则不主动引入：

- React / Vue / 大型组件库
- 自建 Node 后端
- ORM / Docker / 微服务
- 复杂状态管理
- 大型设计系统
- 通用账号/权限体系
- 为了“架构完整”而存在的多层抽象

如果跨设备同步需要云端，只增加一个很薄的同步层，不改变前端优先的整体结构。

## 第一阶段产品范围

新版第一阶段只做真正有复习价值的东西：

- **今日**：根据到期复习、薄弱点、新学、真题和论述安排当天任务
- **知识**：四科知识框架、搜索、核心结论、答题骨架和作品证据
- **训练**：先回答再看反馈的真题/论述训练
- **进度**：最简单可解释的“不会 / 会了”复习状态
- **备份/同步**：保证电脑和手机之间能继续同一份学习状态

暂不优先：排行榜、成就系统、复杂统计大屏、社交、卡组市场、PDF 阅读器、OCR、知识图谱展示、完整 AI 聊天客户端等。

## 内容来源

新版不会直接把旧 Android 版 1101 个知识点原样搬过来。

内容路线是：

**高校公开课程定骨架 → 教材/原典核知识 → 南师大历年真题定优先级 → 旧 Android 内容做候选材料 → 整理成适合回忆和答题的主专题。**

当前已建立：

- `docs/content-source-catalog-v1.md`：公开/免费资料源目录
- `docs/content-anchors-v1.json`：四科结构锚点
- `docs/content-audit-2026-09-29.md`：Android v2.26.0 内容审计
- `docs/content-core-batch-v1.md`：新版第一批高价值核心专题
- `tools/audit_content.py`：零依赖内容审计脚本

## 当前审计结论

旧 Android seed v2.26.0：

- 1101 个知识点
- 564 道真题，其中 142 道论述题
- 909 条旧写作材料
- 564/564 真题已有 `answer_framework`
- 只有 201/1101 知识点有非占位来源
- 516 个 HIGH 高频知识点中只有 39 个有有效来源
- 只有 3/564 道真题显式关联知识点

因此新版的第一优先级不是继续加数量，而是：

**高频知识补来源 + 真题绑定知识点 + 把内容变成真正可训练的结构。**

## 仓库现状

当前 `main` 仍保留早期 Demo：知识点浏览、选择题练习、翻转卡片。

新版重构会逐步替换它，但不会为了“重构彻底”一次性推倒所有可用代码。每次改动优先产出一个可以实际使用的小版本。

## 运行当前版本

直接打开 `index.html`，或启动任意静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 项目底线

这不是一个要长期商业化的软件工程项目。

如果某个方案需要多写三倍代码，只是为了“更标准”“以后可能扩展”，默认不选。

**软件的价值，以它能不能让我更快开始学习、更容易记住、更会答题为准。**
