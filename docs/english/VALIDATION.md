# Wenyan 英语真实使用验收

目的：在继续语境训练或云同步前，确认 E1—E4 在真实浏览器和 Android 上确实可用。

这不是自动测试替代品，也不允许把缩窄桌面窗口写成“Android 已通过”。

## 0. 验收对象

当前最新英语链：

```text
PR #5 固定词库 / 智能队列
→ PR #6 单词详情
→ PR #7 音标 / 词形 enrichment
→ PR #8 轻量学习反馈
```

验收优先使用 PR #8 最新 head，因为它包含前面全部 stacked 改动。

## 1. 开始前

```bash
npm ci
npm test
npm run build
npm run dev -- --port 4173
```

自动测试 / 构建必须先通过。

浏览器人工测试建议使用隔离存储：

```text
http://localhost:4173/?test=baseline#english
```

`?test=baseline` 使用独立的 `wenyan-baseline:*` localStorage 前缀，不操作真实个人记录。验收前可清理该前缀下旧测试数据。

## 2. 固定词库

打开英语页，确认：
- 不显示“24 个演示词”作为主词库状态。
- 默认是“核心”层。
- 能看到约 1200 核心词 + 必要兼容种子词的状态说明。
- 切到“高频”，范围约 2444。
- 切到“完整”，唯一词条总数为 5528。
- 页面不会一次生成 5528 行 DOM；列表有显示上限提示。
- 搜索未出现在可见前 300 行的词仍能找到。

网络依赖检查：
- 正常页面应优先请求同源 `/data/english/netem-v1.json`。
- 阻断 `raw.githubusercontent.com` 和 `cdn.jsdelivr.net` 后，正常同源词库仍可工作。
- **不要宣称 PWA 式完全离线**：当前如果整个站点本身不可访问，应用并不承诺离线冷启动。

## 3. 三种训练模式

### 跟打

检查：
1. 显示英文、音标（有数据时）和释义。
2. 首次完整输入正确可前进。
3. 首次拼错后必须清空并完整订正，不能自动补正确答案。
4. 完成跟打只产生 `typing`，不应进入主动回忆 FSRS 评分。

### 默写

检查：
1. 只看释义回忆英文。
2. 首次拼错 → 展示单词 → 强制完整订正。
3. 订正后仍保留 `firstCorrect:false`。
4. “没想起 / 想起来了”进入 FSRS。
5. 使用提示后不能按“想起来了”伪装成功。

### 听写

检查：
1. 进入题目能播放英语发音。
2. 未播放且未提示时不能直接提交作弊。
3. 拼错 / 订正 / 自评语义与默写一致。

## 4. 智能队列与错词

至少制造三类状态：
- 一个到期复习词。
- 一个近期首次拼错词。
- 若干未学新词。

开始“智能开始”后确认顺序：

```text
到期 → 近期错词 → 新词
```

然后：
- 在错词页能看到近期错词。
- 对该词后续正确完成后，旧错误不应永久把它锁在近期错词状态。
- undo 最近一次评价后，错词 / 复习状态随事件恢复。

## 5. 单词详情

随机检查至少 10 个词，包括：高频词、较低频词、有词形变化词、无词形变化词。

应能看到有值才显示：
- 音标。
- 核心中文义。
- 考研排名 / 词频。
- 分类 / 子分类。
- 其他拼写。
- 词形变化。
- 当前学习状态。
- 近期错词 / 收藏。
- 复习次数 / 下次复习提示。

当前不要求词性：固定 ECDICT 数据的 `pos` 覆盖为 0，不能用空数据冒充已接入。

## 6. 今日轻量反馈

完成几次真实操作后确认：
- 今日新学：只在第一次主动回忆时增加；跟打不增加。
- 主动复习：只统计今天 `review`。
- 当前到期：与实际待复习队列一致。
- 首次正确率：提示、忘记或首次拼错不算成功。
- 拼写错误：跟打 / 默写 / 听写首次拼错都能反映，但同一个已记录结果不重复累计。
- undo 后统计同步回退。

## 7. 刷新与旧 session

必须检查：
1. 开始 6—12 词训练。
2. 完成 2—3 词，中途刷新。
3. 继续入口回到正确位置。
4. 如果当前词首次已经拼错、正在订正，刷新后首次错误不能消失。
5. 用旧 v0.1 结构的未完成英语 session 测一次升级续学；不能因为词库扩大而找不到旧种子词。

## 8. Android 真机

至少检查常用 Android 浏览器一次：
- 软键盘弹出后输入框仍可见。
- 提交 / 提示 / 发音按钮可触达。
- 360—430px 宽度没有横向滚动。
- 短屏幕能纵向滚到操作区。
- 英文 TTS 实际能播；失败时提示合理。
- 连续训练 30—50 词没有明显卡顿或输入延迟。
- 完整词库层打开 / 搜索不会因为大量 DOM 卡死。
- 暂停、返回、再进入行为自然。

记录设备 / 浏览器版本；没有测过的项目写“未验证”。

只有核心闭环和 Android 使用通过后，才继续：
1. 根据真实卡点补少量快捷键 / 手机细节。
2. 高频难词 / 反复错词语境强化。
3. 单人薄云同步：电脑 ↔ 手机继续同一学习状态。

文学仍保持冻结，直到英语连续使用稳定。
