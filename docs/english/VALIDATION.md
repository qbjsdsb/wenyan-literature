# Wenyan 英语桌面真实使用验收

目的：在把当前整合基线合入 `main` 前，确认英语核心闭环在**真实桌面浏览器**中可以稳定连续使用。

这不是自动测试替代品，也不允许把“代码能构建”写成“真实使用已通过”。

## 0. 验收对象

当前验收对象：

`integration/desktop-english-baseline-v1`

它整合了此前 PR #2—#10 的最新有效英语成果。

当前不做 Android / iOS 验收。

## 1. 开始前

```bash
npm ci
npm test
npm run build
npm run dev -- --port 4173
```

自动测试 / 构建必须先通过。

浏览器人工测试建议使用隔离存储：

```text
http://localhost:4173/?test=baseline#english
```

`?test=baseline` 使用独立 localStorage 前缀，不操作真实个人记录。

## 2. 桌面环境

至少检查：
- Chromium 系桌面浏览器一款（Chrome / Edge 均可）。
- 常用电脑分辨率。
- 浏览器缩放 100%。
- 键盘连续输入。

重点不是做“多浏览器兼容矩阵”，而是确认本人真实使用环境稳定。

## 3. 固定词库与层级

打开英语页，确认：
- 默认主词库不是 24 个兼容词。
- 默认“核心”层正常。
- 切到“高频”，范围约 2444。
- 切到“完整”，唯一学习 ID 为 5528。
- 列表不会一次生成 5528 行 DOM。
- 搜索未出现在首屏列表中的词仍能找到。
- 切换层级不会破坏当前未完成 session。

数据加载：
- 正常页面优先读取随应用发布的固定 NETEM 快照。
- 不依赖上游 `master` 才能开始训练。
- 固定 ECDICT enrichment 失败时不应阻塞基础训练。

## 4. 三种训练模式

### 跟打
检查：
1. 显示英文、释义，音标有数据时正常显示。
2. 首次完整输入正确可继续。
3. 首次拼错后必须完整订正。
4. 跟打只产生 typing 结果，不冒充主动回忆 FSRS 成功。

### 默写
检查：
1. 只看释义回忆英文。
2. 首次拼错后展示正确词并要求完整订正。
3. 订正后仍保留 `firstCorrect:false`。
4. 自评进入 FSRS。
5. 使用提示后不能被统计成无提示首次正确。
6. 点提示后立即刷新，hinted 状态仍存在。

### 听写
检查：
1. 发音按钮可用。
2. 拼错 / 订正 / 自评语义与默写一致。
3. TTS 失败时不应导致训练状态丢失。

## 5. 智能队列与错词

至少制造：
- 一个到期词。
- 一个近期首次拼错词。
- 若干未学新词。

确认默认顺序：

```text
到期 → 近期错词 → 新词
```

再确认：
- 错词筛选能看到近期错词。
- 后续正确完成后，不被旧错误永久锁在错词状态。
- undo 最近一次评价后，状态同步回退。

## 6. Session 完整性

必须检查：
1. 开始 6—12 词训练。
2. 完成 2—3 词后刷新。
3. 继续入口回到正确位置。
4. 当前词首次拼错、正在订正时刷新，首次错误不能消失。
5. 点击提示但未提交时刷新，hinted 不能消失。
6. 有未完成组时，“智能开始”不能覆盖它。
7. 在完整层开始包含低频词的 session，再切回核心层，当前组仍能完成。
8. 用旧 v0.1 结构的未完成英语 session 测一次升级续学。

## 7. 单词详情

随机检查至少 10 个词，覆盖：
- 高频词。
- 低频词。
- 有词形变化词。
- 无词形变化词。
- `may` / `march` 这类历史规范化重复项。

有值才显示：
- 音标。
- 中文义。
- 考研排名 / 词频。
- 分类 / 子分类。
- 变体。
- 词形变化。
- 当前学习状态。
- 错词 / 收藏。
- 复习次数 / 下次复习提示。

当前不要求词性，因为固定 ECDICT 数据没有可靠 `pos` 覆盖。

## 8. 今日轻量反馈

完成几次真实操作后确认：
- 今日新学只在第一次主动回忆时增加；跟打不增加。
- 主动复习只统计今天 review。
- 当前到期与实际待复习队列一致。
- 首次正确率不会把提示、忘记、首次拼错算成成功。
- 拼写错误能反映三种模式的首次拼错。
- 旧 review 缺少 `firstCorrect` 时不会污染正确率。
- undo 后统计同步回退。

## 9. 键盘与连续训练

连续训练至少 30—50 词，观察：
- 输入框始终能稳定获得焦点。
- Enter 提交 / 继续自然。
- Esc 暂停不误触其他操作。
- 不出现明显输入延迟。
- 不出现页面跳动导致光标丢失。
- 不出现训练完成后 session 状态异常。

如果快捷键与浏览器默认行为冲突，记录为 P1。

## 10. 长列表与搜索

完整 5528 层检查：
- 打开列表无明显冻结。
- 搜索响应可接受。
- 列表限制生效，不生成几千 DOM 节点。
- 收藏 / 已掌握 / 错词筛选切换自然。

如果性能问题只在大量长期学习历史下才可能出现，记录为“待真实数据 profiling”，不要提前造缓存系统。

## 11. JSON 备份恢复

使用测试存储：
1. 产生收藏、已掌握、review、typing、未完成 session。
2. 导出 JSON。
3. 清空测试前缀数据。
4. 导入 JSON。
5. 刷新。
6. 确认学习记录与未完成 session 恢复。

不能只验证“JSON 能解析”，要验证真实续学状态。

## 12. 静态部署路径

当前 Vite 已改为相对 base。

至少 smoke test：
- 根路径部署可以运行。
- 放在一个子路径下时，JS / CSS / NETEM / ECDICT 静态资源仍能找到。

不要求正式发布，只验证构建产物可搬迁。

2. 整合基线合入 `main`。
