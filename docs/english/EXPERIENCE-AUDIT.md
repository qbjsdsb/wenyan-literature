最高优先级是逻辑：当前智能选词默认 follow，仅写 typing。到期词不完成主动 review。只改 CSS 无法修复。

参考原则（只借鉴交互，不复制代码）：
- [Qwerty Learner](https://github.com/RealKai42/qwerty-learner)：当前词聚焦、完整拼写输入。
- [TypeWords](https://github.com/zyronon/TypeWords)：默认智能学习与自由练习分开。
- [Raycast](https://manual.raycast.com/keyboard-shortcuts)：上下键选择、Enter 主动作、上下文轻提示。
- Mobbin 实际返回需付费计划，本轮没有取得或声称审查其屏幕。
