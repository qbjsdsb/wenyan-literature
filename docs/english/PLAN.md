# Wenyan 英语专项推进方案

更新：2026-10-06。

当前策略：**先把英语做成每天可以长期使用的完整模块，再恢复文学内容开发。**

## 1. 产品目标

英语模块服务个人考研英语，不做“大而全背单词 App”。核心目标：
- 打开就知道今天该背什么。
- 键盘输入为核心，不只是看卡片。
- 拼错必须完整订正。
- 主动回忆结果进入长期复习调度。
- 手机与电脑都能快速连续学习。
- 数据本地优先，最终做单人薄同步。

一句话：**减少选择，强化主动回忆，让学习记录可靠积累。**

## 2. 已完成的本地功能

### 基础训练器
- 跟打 / 默写 / 听写。
- 拼错后整词订正。
- 首次正确 / 错误保留。
- 收藏 / 已掌握。
- `ts-fsrs`。
- 未完成 session 刷新续学。
- JSON 备份恢复。

### E1 — 固定词库与分层
- 固定 NETEMVocabulary 版本并随应用发布快照。
- 5530 上游行 → 5528 唯一词。
- 核心 1200 / 高频 2444 / 完整 5528。
- 旧 24 种子词保留兼容。
- 词库与学习状态分离。

### E2 — 智能队列与错词

默认：

`到期复习 → 近期错词 → 新词`

- 错词从现有事件派生。
- 后续正确可清除旧错词派生状态。
- undo 生效。
- 英语页有错词过滤。

### E3-A — 单词详情
- 考研排名 / 词频。
- 分类 / 子分类。
- 变体。
- 新词 / 到期 / 复习中 / 已掌握。
- 近期错词 / 收藏。
- 复习次数与下次复习信息。

### E3-B — 音标与词形

固定 ECDICT enrichment，仅提取结构化字段，不导入另一套释义 / 例句。

覆盖：
- 目标 5528。
- 匹配 5519。
- 音标 5509。
- 词形变化 4621。
- 当前固定版本 `pos` 为 0，因此不冒充已有词性。

### E4 — 轻量学习反馈
- 今日新学。
- 主动复习。
- 当前到期。
- 首次正确率。
- 拼写错误。

所有统计从 `wenyan-events-v2` 派生，不新增统计数据库。

## 3. 当前唯一优先级：真实使用验收

**现在先停止盲目增加英语功能。**

按 [`VALIDATION.md`](VALIDATION.md) 验收：
- 桌面真实浏览器。
- Android 真实软键盘。
- Android TTS。
- 1200 / 2444 / 5528 层级切换。
- 跟打 / 默写 / 听写。
- 智能队列和错词回流。
- 详情数据。
- 日统计。
- 刷新续学和旧 session 兼容。
- 手机长列表性能。

发现 P0/P1 问题先修，不以“功能更多”掩盖真实使用问题。

## 4. 成熟产品借鉴边界

### Qwerty Learner
保留错误肌肉记忆原则：拼错后完整重输；速度 / 正确率只做轻反馈。

### TypeWords
借鉴智能队列、错词、收藏、已掌握与详情信息，不照搬复杂度。

### Clozemaster
只在本地核心闭环稳定后借鉴语境挖空；不批量给所有词制造例句。

### FSRS
继续使用 `ts-fsrs`，不自行重写算法。跟打不等于记住，只有主动回忆进入长期评分。

## 5. 稳定词库模型

当前字段：

```text
id
word
meaning
rank
frequency
variants
category
subcategory
ipa
exchange
```

`pos` 字段结构已预留，但当前没有可靠覆盖，不展示假数据。

增强字段必须来自许可清晰、版本可固定的数据源。

## 6. 验收通过后的阶段

### E5 — 少量真实体验优化

只根据验收和连续使用出现的问题改：
- 桌面快捷键。
- 手机焦点 / 软键盘。
- 发音按钮。
- 训练节奏。
- 必要的列表 / 搜索细节。

### E6 — 语境强化

只优先给：
- 高频多义词。
- 反复错词。
- 阅读中容易认不出的词。

形式：句子挖空 → 主动输入 → 完整句 / 说明；来源必须可追溯。

### E7 — 单人薄云同步

目标：电脑背到哪里，手机继续。

只同步：
- `wenyan-events-v2`。
- 未完成英语 session。
- 收藏 / 已掌握。
- 词库层级和少量英语偏好。

词库 / 音标 / 词形快照随应用版本发布，不在设备间同步。

## 7. 电脑与手机原则

### 电脑
- Enter 提交 / 继续。
- Esc 暂停。
- 数字键评分。
- 输入框自动 focus。
- 快捷键以真实高频操作为准，不为了“专业感”堆快捷键。

### 手机
- 输入框不被软键盘遮挡。
- 操作按钮短视口可达。
- 不一次渲染几千 DOM 节点。
- 发音按钮易点。
- 连续训练不应明显卡顿。

## 8. 当前冻结

英语本地核心未通过真实设备验收前：
- 不扩文学知识库。
- 不接文学真题。
- 不重做文学页。
- 不做文学同步特化。
- 不做排行榜、积分商城、强签到。
- 不批量生成 5528 个语境句。
