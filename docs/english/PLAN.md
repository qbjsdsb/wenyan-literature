# Wenyan 英语专项推进方案

更新：2026-10-06。

当前策略：**先把英语做成每天可以长期使用的完整模块，再恢复文学内容开发。**

## 1. 产品目标

英语模块服务个人考研英语，不做“大而全背单词 App”。核心目标：
- 打开就知道今天该背什么。
- 键盘输入为核心，不只是看卡片。
- 拼错必须完整订正。
- 主动回忆结果进入长期复习调度。
- 手机与电脑都能快速连续学习。
- 数据本地优先，后续做单人薄同步。

一句话：**减少选择，强化主动回忆，让学习记录可靠积累。**

## 3. 成熟产品借鉴边界

### Qwerty Learner
保留“输入肌肉记忆”思路：拼错不自动修正，必须完整重输。速度/正确率只做轻量反馈。

### TypeWords
借鉴智能队列、错词、收藏、已掌握和详情增强；不要照搬复杂度。

### Clozemaster
借鉴“高频优先 + 语境强化”，但语境后置，先把快速单词训练做好。

### FSRS
继续使用 `ts-fsrs`，不自己造算法。跟打不等于记住；真正主动回忆才进入长期评分。

## 4. 稳定词库模型

当前最小字段：

```text
id
word
meaning
rank
frequency
variants
category
subcategory
```

未来增强字段：

```text
phonetic
pos
ukPronunciation
usPronunciation
phrases
examples
roots
```

增强字段必须来自许可清晰的数据源，不能为了“内容丰富”直接复制版权不清的词典内容。

## 5. 当前唯一开发重点：E3 单词详情与信息质量

先不引入新的大数据源，优先把已有字段用好。

### E3-A：详情页已有数据

点击单词后应快速看到：
- 单词。
- 已有音标（24 个兼容种子词有则显示）。
- 核心中文义。
- 考研词频排名。
- 词频值。
- 分类 / 子分类。
- 其他拼写 / 变体（有才显示）。
- 当前学习状态：新词 / 到期 / 下次复习。
- 最近是否为错词。
- 收藏 / 已掌握 / 发音。

不要把训练主屏做成词典页。

### E3-B：音标 / 词性数据源

E3-A 稳定后再审核新的词典数据源：
- 许可证是否允许在个人项目中存储/分发。
- 覆盖考研 5528 唯一词的比例。
- 音标和词性质量。
- 是否能固定版本并生成自己的规范化快照。

如果数据源不够干净，宁可暂时保持浏览器 TTS + 外部词典核对，也不污染仓库。

## 6. 后续阶段

### E4：长期使用反馈
- 今日新学。
- 今日复习。
- 当前到期。
- 首次正确率。
- 今日拼写错误数。
- 跟打速度 / 字母正确率（轻量）。
- 增加真正有用的桌面快捷键和手机操作细节。

不做排行榜、积分商城、强签到等低价值游戏化。

### E5：语境强化

只优先给：
- 高频多义词。
- 连续错词。
- 阅读中容易认不出的词。

形式：句子挖空 → 主动输入 → 展示完整句和说明。来源必须可追溯。

### E6：真机收口 + 单人薄云同步

先完成 Android 软键盘、发音、短视口、未完成 session 真实检查；之后同步：
- `wenyan-events-v2`。
- 未完成英语 session。
- 收藏 / 已掌握。
- 词库层级和少量英语偏好。

词库本体随应用版本发布，不在设备间同步。

## 7. 电脑与手机原则

### 电脑
- Enter 提交/继续。
- Esc 暂停。
- 数字键完成记忆评价。
- 输入框自动 focus。
- 后续可增加发音/提示快捷键。

### 手机
- 输入框不被软键盘遮挡。
- 提交按钮短视口可达。
- 长词表不渲染几千 DOM 节点。
- 发音按钮易点。

## 8. 当前冻结

英语核心未完成前：
- 不扩文学知识库。
- 不接新的文学真题。
- 不重新设计文学页。
- 不做文学同步特化。
- 不为了未来文学需求重构英语数据结构。
