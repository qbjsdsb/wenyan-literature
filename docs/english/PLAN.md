# Wenyan 英语专项推进方案

更新：2026-10-06。

本文件只负责英语专项。当前项目策略是：**先把英语做成每天可以长期使用的完整模块，再恢复文学内容开发。**

## 1. 产品目标

英语模块不是再做一个“大而全背单词 App”，而是服务个人考研英语：

- 打开就知道今天该背什么。
- 键盘输入为核心，不只是看卡片。
- 拼写错误必须真正订正。
- 主动回忆结果进入长期复习调度。
- 手机与电脑都能快速连续学习。
- 数据本地优先，后续可薄同步。

一句话：**减少选择，强化主动回忆，让学习记录可靠积累。**

## 2. 当前已经有的能力

Web v0.1 已有：
- 跟打。
- 默写。
- 听写。
- 拼错后订正。
- 首次正确/错误记录。
- 收藏。
- 已掌握。
- FSRS 复习调度。
- 未完成 session 刷新续学。
- JSON 备份恢复。

PR #3 正在把 24 个演示词升级为 NETEMVocabulary 5530 词目录，并先激活前 1200 高频词。

因此后续不应重写训练器，而应把**数据、队列、反馈和可靠性**补齐。

## 3. 参考产品研究结论

### Qwerty Learner：最值得保留的是“错误肌肉记忆”原则

其设计目标就是把背词与英文输入肌肉记忆结合；输入错误后要求整词重新输入，并提供音标、发音、默写、速度与正确率。

Wenyan 应继续坚持：
- 跟打阶段实时发现错误。
- 错了不自动补全到正确答案。
- 完整重输正确单词后才能前进。
- 速度/正确率只作为反馈，不成为游戏化目标。

### TypeWords：最值得借鉴的是“智能队列 + 错词体系”

TypeWords 已有跟写、听写、自测、默写，智能模式与自由模式，以及错词本、收藏、已掌握、音标、发音、例句、短语、同根词等。

Wenyan 不需要照搬它的复杂度，但应借鉴：
- 默认智能模式。
- 错词自动进入专项复习。
- 收藏 / 已掌握互不混淆。
- 详情页可逐步补充词性、短语、同根词等信息。

### Clozemaster：最值得借鉴的是“高频优先 + 语境后置”

Clozemaster 的核心不是词表，而是按频率组织句子并做 cloze 主动回忆。

Wenyan 的应用方式：
- 新词阶段仍然快速背词。
- 只有高频难词/反复错词再进入语境强化。
- 语境题优先输入，不以选择题为主。

### FSRS：调度不要自己造

当前已经使用 `ts-fsrs`，继续沿用。

关键规则：
- 真正忘记要记录为失败，不能因为“看答案后觉得会”就算成功。
- 跟打的视觉输入不应和主动回忆混成同一种记忆评分。
- 评分语义一旦建立，不随便改，否则历史复习记录会失真。

## 4. 词库策略

### 4.1 固定上游版本

不要长期在运行时静默读取 `master`。

建议下一步固定一个明确的 NETEMVocabulary release / commit，生成 Wenyan 自己的规范化快照。

原因：
- 上游释义或排序变化不会突然影响已有学习记录。
- 首次使用可以离线。
- 构建与测试可复现。
- 数据更新可以单独做一个可审查 PR。

### 4.2 数据和代码分离

建议结构：

```text
src/
  english/
    catalog.js        # 查询、分层、筛选
    queue.js          # 智能学习队列
    practice.js       # 后续需要时再从 app.js 迁移，避免过早拆分

public/data/english/
  netem-v7.json       # 规范化快照（示例命名）

docs/third-party/
  NETEMVocabulary-DATA.md
```

不要求马上拆 `app.js`。只有英语逻辑继续增长到难维护时再拆。

### 4.3 三层学习范围

建议：
- **核心**：前 1200。
- **高频**：前 2444（上游说明其出现频率显著更高）。
- **完整**：5530。

默认新用户从“核心”开始。

切换范围只改变“哪些新词可以进入队列”，不能删除旧复习记录。

### 4.4 词条字段

稳定最小字段：

```text
id
word
meaning
rank
frequency
variants
category
subcategory
```

后续增强字段：

```text
phonetic
pos
ukPronunciation
usPronunciation
phrases
examples
roots
```

增强字段可以来自其他许可清晰的数据源，不要阻塞第一版。

## 5. 智能队列

默认“开始学习”不让用户做一堆选择。

建议优先级：

```text
A. 已到期复习
B. 近期反复错词
C. 当前未完成 session
D. 当日新词
```

### 新词额度

保留 6 / 12 / 24，默认 12。

后续可根据真实使用增加：
- 今天少学：6
- 标准：12
- 集中：24

不要做复杂计划系统。

### 错词强化

一个词满足任一条件进入错词队列：
- 首次拼写错误。
- 默写失败。
- 听写失败。
- FSRS 评级为 Again。

错词不是另一套数据副本，而是从事件记录计算出来。

## 6. 三种训练模式的职责

### 跟打

目的：建立正确拼写和输入肌肉记忆。

- 显示词、核心义、可选音标。
- 拼错立即提示位置。
- 需要整词重输。
- 不把“看着答案打出来”当成长期记忆成功。

### 默写

目的：中文义 → 英文主动回忆。

这是长期复习的主模式之一。

- 先只显示核心中文义。
- 用户完整输入。
- 错后显示正确词并订正。
- 再做“不会 / 会了”或稳定评分映射。

### 听写

目的：声音 → 拼写。

- 默认先播放再输入。
- 可重播。
- 提示使用后需要降低本次记忆评价或只记为练习。
- TTS 不可靠时可降级，不阻塞学习。

## 7. 单词详情

不要一开始做成巨大词典。

第一阶段详情页只需要：
- 单词。
- 音标。
- 核心义。
- 词性。
- 发音。
- 收藏 / 已掌握。
- 当前学习状态（新词 / 到期 / 下次复习）。

第二阶段才考虑：
- 常用短语。
- 同根词。
- 近义词辨析。
- 词源。
- 例句。

## 8. 语境层

语境是增强，不是主入口。

优先给：
- 高频但多义的词。
- 连续错 2–3 次的词。
- 只会中文义但在阅读中识别困难的词。

形式：

```text
句子（挖空）
→ 用户输入目标词
→ 展示完整句子 + 中文说明
→ 标记是否需要再次复习
```

数据来源必须可追溯。可研究 Tatoeba 的 CC BY/CC0 句子，但进入正式库前需保留来源/许可；也可以使用自行编写并人工核验的考研风格例句，并明确其为自编例句。

## 9. 反馈与统计

只显示能指导下一步学习的数字。

英语首页建议最多显示：
- 今天新学。
- 今天已复习。
- 当前到期。
- 首次正确率。
- 今日拼写错误数。

训练结束建议显示：
- 本组词数。
- 首次答错词。
- Again / 遗忘词。
- 一键再练错词。

跟打可以额外显示：
- WPM / 输入速度。
- 字母正确率。

不做：
- 排行榜。
- 连续签到惩罚。
- 积分商城。
- 大量动画奖励。

## 10. 手机与电脑

### 电脑

目标：手基本不离键盘。

- Enter 提交/继续。
- Esc 暂停。
- 数字键完成记忆评价。
- 快捷键播放发音 / 提示。
- 自动 focus 输入框。

### 手机

目标：单手和软键盘稳定。

- 输入框不被键盘遮挡。
- 提交按钮在键盘/短视口下可达。
- 不自动弹大量面板。
- 长词表不要渲染 5530 个 DOM 节点。
- 发音按钮大且易点。

## 11. 云同步何时做

英语本地版稳定之后立即做，而不是等文学完成。

同步最先服务：
- `wenyan-events-v2`。
- 未完成英语 session。
- 收藏 / 已掌握。
- 当前词库范围和少量英语偏好。

词库本体不要每台设备互相同步；应用版本自带同一数据快照即可。

## 12. 推荐开发顺序

### Sprint E0 — PR #3 运行验收

只验证，不扩功能。

### Sprint E1 — 固定词库快照 + 三层词库 + 性能

这是最重要的基础改造。

### Sprint E2 — 智能模式 + 错词专项

让用户打开就能学。

### Sprint E3 — 音标/词性/发音完善 + 单词详情

提升内容质量。

### Sprint E4 — 轻量统计 + 快捷键 + 手机细节

提升长期使用舒适度。

### Sprint E5 — 语境训练

只做高价值词，不全量给 5530 词造例句。

### Sprint E6 — 单人薄云同步

完成电脑 ↔ 手机闭环。

之后才恢复文学开发。

## 13. 本阶段明确冻结

直到 E0–E6 至少完成核心部分：
- 不扩文学知识库。
- 不接新的文学真题。
- 不重新设计文学页。
- 不做文学云同步特化。
- 不为了未来文学需求改英语数据结构。

英语先做好，再继续。
