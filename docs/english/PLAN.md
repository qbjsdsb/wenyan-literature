# Wenyan 英语专项推进方案

更新：2026-10-06。

当前策略：**先把英语电脑端做成每天可以长期使用的完整模块，再恢复文学。**

## 1. 产品目标

英语模块服务个人考研英语，不做“大而全背单词 App”。

核心目标：
- 打开就知道今天该背什么。
- 键盘输入是主交互，不只是看卡片。
- 拼错必须完整订正。
- 主动回忆结果进入长期复习调度。
- 学习记录可靠积累，刷新 / 重开后能继续。
- 本地优先，备份可靠。

一句话：**减少选择，强化主动回忆，让电脑端可以每天直接用。**

### E4.1 — session 完整性

## 3. English Experience v2：Smart Session

本分支已实施，PR #12 保持 Draft。默认入口是“开始今天学习”，不先选模式。

| 词状态 | 第一步 | 后续 | 正式事件 |
| --- | --- | --- | --- |
| 到期 / 近期错词 | 中文义 → 英文主动回忆 | 失败显示答案并完整订正；本组稍后回流一次 | review |
| 新词 | 英文 / 音标 / 中文义 → 完整跟打 | 尽量隔 3 个其他词步骤后主动回忆 | 接触 typing；回忆 review |
| 自由跟打 | 完整拼写练习 | 保留原训练工具 | typing，不改变 FSRS |
| 自由默写 / 听写 | 保留原主动练习语义 | 自评明确用于复习安排 | review |

Smart 首次拼错或使用提示 / 发音提示：本次按 Again，不允许把订正当 Good。`firstCorrect` 保存第一份作答，之后订正不覆盖。成功自评优先聚焦“想起来了”，Enter 可继续。

### 有界组计划与数据兼容

事件 schema 仍为 2，所有原 storage key、ID、review / typing / mastered / favorite / undo 语义保留。可选 session 字段 `smart:1`、`steps`（e 接触 / r 回忆 / x 回流）随原 session 事件保存；旧 session 没有这些字段时按原模式恢复。

现有事件限制 queue ≤ 50、value ≤ 8192 字符不扩大。最多 24 个不同词；预算 48 个步骤，预留每词最多一次失败回流，新词还预留接触步骤。只含新词且目标 24 时，一组最多 16 个，余下目标下一组完成。

回流尽量隔 3 个其他词步骤，绝不连续立即重复，不无限循环。组尾已没有其他词可间隔时，错误留在到期 / 错词池，下一组再复习。只有极少未学词剩余时，间隔可短于 3，不凭空增加填充词。

当前订正 / 自评阶段、hinted 和首次结果即时保存。刷新、JSON 导入恢复同一组步骤计划，不静默重建计划或清空数据。Undo 删除实际学习事件，并恢复该步和它引入的回流位置。

### 页面与交互

英语主入口前置，学习安排 / 自由练习作为次级 disclosure。今日优先续学 → 到期 → 错词 → 新词，文学保留为次级入口。详情先展示释义、状态、下次复习和发音 / 收藏 / 已掌握，数据与许可折叠保留。继续现有字体与灰绿，不引入新视觉系统。

输入区内按键按正常英文处理；IME composing 期间不提交、不切词。训练输入区外支持 Space / H / F / M、评分 1 / 2；Esc 暂停；搜索支持 /、↑↓、Enter。动画仅轻淡入和色彩反馈，尊重 reduced-motion。

实施前审计见 [`EXPERIENCE-AUDIT.md`](EXPERIENCE-AUDIT.md)，本轮验收见 [`EXPERIENCE-VALIDATION.md`](EXPERIENCE-VALIDATION.md)。下一步快速筛词，本轮只明确设计与测试方向，不实现新筛词工具。

## 4. 桌面交互原则

- 输入框自动 focus。
- Enter 提交 / 继续。
- Esc 暂停。
- 数字键只在确实高频时用于评分。
- 键盘操作优先，鼠标操作完整可用。
- 不为了“专业感”堆一堆记不住的快捷键。
- 长列表不一次渲染几千 DOM 节点。
- 训练页尽量稳定，不频繁跳布局。

当前不维护 Android / iOS 专项交互。

## 5. 成熟产品借鉴边界

### Qwerty Learner
保留错误肌肉记忆原则：拼错后完整重输；速度 / 正确率只做轻反馈。

### TypeWords
借鉴智能队列、错词、收藏、已掌握与详情信息，不照搬复杂度。

### Clozemaster
语境训练后置；不批量给所有词制造例句。

### FSRS
继续使用 `ts-fsrs`，不自行重写算法。跟打不等于记住，只有主动回忆进入长期评分。

## 7. 验收后的阶段

### E5 — 收口 main + 固定电脑端入口
- 只修桌面验收发现的 P0 / P1。
- 新整合基线通过测试与构建。
- 安全合入 `main`。
- 提供稳定电脑端访问地址。
- 保留 JSON 备份 / 导入。

### E6 — 真实使用后的个人化优化
只根据真实卡点改：
- 快速筛词 / 快速标已掌握。
- 更合理的到期排序。
- 默认新词量。
- 真正高频的快捷键。
- session 日志压缩。
- 长期学习记录性能。

不要提前硬编码一份“你应该会哪些基础词”的主观黑名单。

### E7 — 可选薄同步
只有以后出现真实多电脑切换需求才做。

原则：
- 本地永远先写。
- 单人使用。
- 不做完整账号体系。
- 不同步 5528 词库本体。
- JSON 备份始终保留。

如果长期只用一台电脑，这一阶段可以永久跳过。

### E8 — 语境强化
只优先给：
- 高频多义词。
- 反复错词。
- 阅读中容易认不出的词。

形式：句子挖空 → 主动输入 → 完整句 / 说明；来源必须可追溯。
