# Wenyan 英语专项推进方案

更新：2026-10-06。

当前策略：**先把英语电脑端做成每天可以长期使用的完整模块，再恢复文学。**

## 1. 产品目标

英语模块服务个人考研英语，不做“大而全背单词 App”。

核心目标：
- 打开就知道今天该背什么。
- 键盘输入是主交互，不只是看卡片。
- 拼错必须完整订正。
- 主动回忆结果进入长期复习调度。
- 学习记录可靠积累，刷新 / 重开后能继续。
- 本地优先，备份可靠。

一句话：**减少选择，强化主动回忆，让电脑端可以每天直接用。**

## 2. 已完成的本地功能

### 基础训练器
- 跟打 / 默写 / 听写。
- 拼错后整词订正。
- 首次正确 / 错误 / hinted 保留。
- 收藏 / 已掌握。
- `ts-fsrs`。
- 未完成 session 刷新续学。
- JSON 备份恢复。

### E1 — 固定词库与分层
- 固定 NETEMVocabulary 版本并随应用发布快照。
- 5530 上游行 → 5528 稳定学习 ID。
- 核心 1200 / 高频 2444 / 完整 5528。
- 旧 24 种子词保留兼容。
- 词库与学习状态分离。
- 重复规范化词条合并义项，不静默丢数据。

### E2 — 智能队列与错词
默认：`到期复习 → 近期错词 → 新词`。

- 错词从现有事件派生。
- 后续正确可清除旧错词派生状态。
- undo 生效。
- 英语页有错词过滤。

### E3 — 单词详情与 enrichment
- 考研排名 / 词频。
- 分类 / 子分类。
- 变体。
- 新词 / 到期 / 复习中 / 已掌握。
- 近期错词 / 收藏。
- 复习次数与下次复习信息。
- 固定 ECDICT 补充音标与词形变化。

当前固定 ECDICT：
- 目标 5528。
- 匹配 5519。
- 音标 5509。
- 词形变化 4621。
- 可靠 `pos` 覆盖为 0，因此不展示假词性。

### E4 — 轻量学习反馈
- 今日新学。
- 主动复习。
- 当前到期。
- 首次正确率。
- 拼写错误。

所有统计从 `wenyan-events-v2` 派生，不新增统计数据库。

### E4.1 — session 完整性
已经修复并补自动测试：
- 切换词库层时，未完成 session 剩余词继续可解析。
- 正式词库尚未载入时不清空 session。
- 有未完成组时，“智能开始”不会覆盖当前组。
- 点击提示立即持久化 `hinted:true`。
- 默写中主动发音也立即记为提示。
- 刷新后第一次提交仍保留此前提示状态。
- 首次正确 / 错误不会被后续尝试覆盖。

### E4.2 — 可维护性收口
已经完成：
- 产品配置集中。
- `word:<id>` key helper 统一。
- 错词语义统一。
- scoped localStorage 隔离。
- 相对部署路径。
- 缺失 rank 使用 `null`。
- 旧 review 不污染首次正确率。
- 24 个兼容词独立到 fallback 模块。

## 3. 当前唯一优先级：桌面真实使用验收

**现在停止增加新的英语训练功能。**

按 [`VALIDATION.md`](VALIDATION.md) 验收当前整合基线：
- 桌面真实浏览器。
- 1200 / 2444 / 5528 层级切换。
- 跟打 / 默写 / 听写。
- 智能队列和错词回流。
- 提示 / 订正 / FSRS 评分。
- 详情数据。
- 日统计。
- 刷新续学和旧 session 兼容。
- 连续 30—50 词性能。
- 完整词库搜索 / 滚动。
- JSON 备份恢复。
- 静态子路径部署。

发现 P0/P1 先修，不以“功能更多”掩盖真实使用问题。

## 4. 桌面交互原则

- 输入框自动 focus。
- Enter 提交 / 继续。
- Esc 暂停。
- 数字键只在确实高频时用于评分。
- 键盘操作优先，鼠标操作完整可用。
- 不为了“专业感”堆一堆记不住的快捷键。
- 长列表不一次渲染几千 DOM 节点。
- 训练页尽量稳定，不频繁跳布局。

当前不维护 Android / iOS 专项交互。

## 5. 成熟产品借鉴边界

### Qwerty Learner
保留错误肌肉记忆原则：拼错后完整重输；速度 / 正确率只做轻反馈。

### TypeWords
借鉴智能队列、错词、收藏、已掌握与详情信息，不照搬复杂度。

### Clozemaster
语境训练后置；不批量给所有词制造例句。

### FSRS
继续使用 `ts-fsrs`，不自行重写算法。跟打不等于记住，只有主动回忆进入长期评分。

## 7. 验收后的阶段

### E5 — 收口 main + 固定电脑端入口
- 只修桌面验收发现的 P0 / P1。
- 新整合基线通过测试与构建。
- 安全合入 `main`。
- 提供稳定电脑端访问地址。
- 保留 JSON 备份 / 导入。

### E6 — 真实使用后的个人化优化
只根据真实卡点改：
- 快速筛词 / 快速标已掌握。
- 更合理的到期排序。
- 默认新词量。
- 真正高频的快捷键。
- session 日志压缩。
- 长期学习记录性能。

不要提前硬编码一份“你应该会哪些基础词”的主观黑名单。

### E7 — 可选薄同步
只有以后出现真实多电脑切换需求才做。

原则：
- 本地永远先写。
- 单人使用。
- 不做完整账号体系。
- 不同步 5528 词库本体。
- JSON 备份始终保留。

如果长期只用一台电脑，这一阶段可以永久跳过。

### E8 — 语境强化
只优先给：
- 高频多义词。
- 反复错词。
- 阅读中容易认不出的词。

形式：句子挖空 → 主动输入 → 完整句 / 说明；来源必须可追溯。

## 8. 当前冻结

英语桌面核心未完成真实验收前：
- 不扩文学知识库。
- 不接文学真题。
- 不重做文学页。
- 不做 Android / iOS 专项。
- 不做排行榜、积分商城、强签到。
- 不批量生成 5528 个语境句。
