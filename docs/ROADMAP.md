# Wenyan 路线图

路线图只解决一件事：**下一步做什么，以及什么暂时不要做。**

当前策略：**Desktop-first + English-first**。

优先级：真实备考价值 > 数据安全 > 开始长期使用 > 开发速度 > 工程美观。

## 当前事实

Desktop English Baseline v1 已于 2026-10-06 通过 PR #11 正式合入 `main`。

英语本地核心已经具备：
- 固定考研词库与 1200 / 2444 / 5528 分层。
- 跟打 / 默写 / 听写。
- `ts-fsrs` 主动回忆调度。
- 到期 / 近期错词 / 新词智能队列。
- 收藏 / 已掌握 / 错词筛选。
- 单词详情、音标、词形、考研排名 / 词频。
- 今日新学、主动复习、到期、首次正确率、拼写错误。
- 刷新续学、旧 session 兼容、提示状态持久化。
- JSON 备份恢复。
- 根路径 / 子路径静态部署能力。

标准 CI、Chromium `dist` smoke 以及合并后的 `main` push CI 均已通过。

文学内容继续冻结。

---

## P0：完成 Smart Session 与桌面体验验收

PR #12（Draft）承接最新 main。到期 review、新词接触 / 回忆分离、有界错词回流是本轮核心；不以更多功能替代体验质量。测试、dist 根 / 子路径 Chromium、三档桌面截图和数据恢复全部留证后交付 Draft，不自动合并或发布。

---

## P1：快速筛词（下一项产品开发）

用本人判断过滤核心 1200 中已经认识的词，不写基础词黑名单。

| 键 | 判断 | 设计边界 |
| --- | --- | --- |
| 1 | 已掌握 | 复用 mastered，保留全部历史，支持撤销 / 恢复 |
| 2 | 模糊 | 留给 Smart 主动回忆，不能伪造一次成功 review |
| 3 | 不会 | 进入新词接触 / 回忆流程，不删除既有 FSRS |

本轮只明确方向，不实现。设计验收：输入 / IME 不误触，单步 undo，刷新 / JSON 恢复，已有 review 保持，新词池排除 mastered，1200 / 2444 / 5528 跨层统计正确。筛选不是 FSRS 评分，不能把“模糊 / 不会”当虚假 review；若需要新状态，要先明确最小兼容方案。

---

## P2：固定入口下的连续真实使用

保持稳定 URL / origin，让学习记录长期积累；发布需用户另外授权，本轮不发布。观察 20—30 分钟训练的焦点、输入、建议新词额度、错词回流和日志增长。优先修真实痛点，再做后续调度 / 性能优化。快速筛词的设计可以先开展，扩展实现应以 Smart 体验稳定为前提。

---

## P3：真实数据驱动的调度与性能优化

只有真实使用证明有价值后再做。

### 到期排序
当前“到期优先”成立，但到期词内部还不是按逾期程度排序。若真实使用中有大量同时到期词，再改为更合理的 due 排序。

### session 日志压缩
当前 session 更新会追加完整状态事件。等长期使用证明备份 / localStorage 明显膨胀后，设计安全压缩：
- 不伤害 review 学习历史。
- 只压缩可替代的旧 session 状态。
- 保证 JSON 备份兼容。

### 长期性能
用真实长期数据 profiling `wordCounts()` / `reviewCard()`；只有确实变慢，再加派生索引或 cache。

---

## P4：可选的单人薄同步

**当前不是必做。**

只有以后出现真实多电脑切换需求时才做。

原则：
- 本机永远先保存。
- 单人使用，不建完整账号 / 权限体系。
- 优先沿用 `wenyan-events-v2` 和稳定事件 ID。
- 5528 词库本体不需要同步。
- 重复同步不产生重复事件。
- 失败不阻塞本地学习。
- JSON 备份继续保留。

如果长期只在一台电脑使用，可以一直不做同步。

---

## P5：语境强化

语境是后置强化层，不阻塞快速背词。

优先对象：
- 反复错词。
- 高频多义词。
- 孤立背会但阅读里仍认不出的词。

形式：
- 短语 / 常见搭配。
- 句子挖空 → 主动输入 → 再展示完整句。

原则：
- 不给 5528 个词批量生成低质量 AI 例句。
- 来源 / 性质可追溯。
- 不抓版权不清的词典正文。

---

## P6：考研英语能力训练

词汇长期稳定后，再把 Wenyan 从背词工具升级成考研英语训练器。

优先顺序建议：
1. 长难句。
2. 真题阅读。
3. 阅读错因体系。
4. 完形 / 翻译 / 新题型。

强调真题驱动和模块联动，不铺一个大而全题库壳。

---

## P7：恢复文学

英语稳定长期使用后再恢复：
- 2023—2026 南师大真题关联。
- 现当代文学 P0 主专题。
- 作家 / 作品证据。
- 名词解释 / 简答 / 比较 / 论述派生训练。
- 文学“今日任务”真实驱动。

仍遵守：有来源、稳定 ID、先答后看、不机械迁移旧 1101 条。

---

## 当前明确不做

- Android / iOS 专项适配。
- 手机软键盘、安全区、触控交互专项维护。
- 新文学专题和真题页面。
- 文学 UI 重设计。
- 排行榜、积分商城、强签到。
- 多人账号 / 权限。
- 为未来可能需求提前重构。
- 继续叠新英语训练模式。
