# Wenyan 路线图

路线图只解决一件事：**下一步做什么，以及什么暂时不要做。**

当前策略：**Desktop-first + English-first**。

优先级：真实备考价值 > 数据安全 > 开始长期使用 > 开发速度 > 工程美观。

## 当前事实

英语本地核心已经具备：
- 固定考研词库与 1200 / 2444 / 5528 分层。
- 跟打 / 默写 / 听写。
- `ts-fsrs` 主动回忆调度。
- 到期 / 近期错词 / 新词智能队列。
- 收藏 / 已掌握 / 错词筛选。
- 单词详情、音标、词形、考研排名 / 词频。
- 今日新学、主动复习、到期、首次正确率、拼写错误。
- 刷新续学、旧 session 兼容、提示状态持久化。
- 近期可维护性整理：配置、key、错词语义、测试隔离、部署路径和重复词义已收敛。

旧 PR #2—#10 形成了一条过长的 stacked 开发链。当前已建立：

`integration/desktop-english-baseline-v1`

作为新的 main 候选基线。

文学内容继续冻结。

## P0：桌面真实验收 + 收拢 main

当前唯一 P0。

### 1. 真实桌面浏览器验收

按 [`english/VALIDATION.md`](english/VALIDATION.md) 检查：
- 核心 / 高频 / 完整词库切换。
- 跟打 / 默写 / 听写。
- 到期 → 近期错词 → 新词。
- 提示、首次错误、强制订正和 FSRS 评分语义。
- 单词详情、音标、词形和统计。
- 刷新续学和旧 session 兼容。
- undo。
- JSON 备份恢复。
- 连续训练 30—50 词。
- 完整词库搜索 / 滚动。
- 根路径和静态子路径部署。

问题分级：
- **P0**：学习记录损坏、session 丢失、评分错误、备份不能恢复。
- **P1**：训练明显卡顿、快捷键 / 焦点阻断主流程、数据展示明显错误。
- **P2**：纯视觉和低频体验细节。

P0/P1 修完再进入 main。

### 2. 收拢旧 stacked PR

旧 PR #2—#10：
- 保留历史和审计价值。
- 不再作为后续开发父链。
- 不要求逐个 merge。

目标是让新的整合 PR 直接从 `main` 展示完整、可审核的桌面英语基线。

完成标准：
- `npm test` 通过。
- `npm run build` 通过。
- 桌面验收结果落盘。
- README / 开发进度 / ROADMAP / PLAN / VALIDATION 与真实状态一致。
- 再安全合入 `main`。

## P1：固定电脑端使用入口

main 基线稳定后，为本人提供一个固定电脑端入口。

目的：
- origin 不再变化。
- localStorage 学习记录可以长期积累。
- 每天打开就能学，不再依赖开发命令。
- 后续问题更容易稳定复现。

优先静态部署，不引入业务后端。

---

## P2：真实使用后的英语优化

先连续真实使用，再做下一轮功能。

优先观察：

### 快速筛词
核心 1200 中会有大量早已掌握的基础词。

不要硬编码主观黑名单；更适合做：
- 快速标“已掌握”。
- 快速保留“模糊 / 不会”。
- 根据真实学习记录调整新词池。

### 到期排序
当前“到期优先”成立，但到期词内部还不是按逾期程度排序。

真实使用证明有价值后，再改为更合理的 due 排序。

### session 日志膨胀
当前 session 更新会追加完整状态事件。

在长期使用 / 备份体积明显增长前，设计安全压缩策略：
- 不伤害 review 学习历史。
- 只压缩可替代的旧 session 状态。
- 保证备份兼容。

### 长期性能
用真实长期数据 profiling `wordCounts()` / `reviewCard()`；只有确实变慢，再加派生索引或 cache。

## P3：可选的单人薄同步

**当前不是 P0。**

只有以后出现真实的多电脑切换需求时才做。

原则：
- 本机永远先保存。
- 单人使用，不建完整账号 / 权限体系。
- 优先沿用 `wenyan-events-v2` 和稳定事件 ID。
- 5528 词库本体不需要同步。
- 重复同步不产生重复事件。
- 失败不阻塞本地学习。
- JSON 备份继续保留。

如果长期只在一台电脑使用，则可以一直不做同步。

---

## P4：语境强化

语境是后置强化层，不阻塞快速背词。

优先对象：
- 反复错词。
- 高频多义词。
- 孤立背会但阅读里仍认不出的词。

形式：
- 短语 / 常见搭配。
- 句子挖空 → 主动输入 → 再展示完整句。

原则：
- 不给 5528 个词批量生成低质量 AI 例句。
- 来源 / 性质可追溯。
- 不抓版权不清的词典正文。

---

## P5：恢复文学

英语稳定长期使用后再恢复：
- 2023—2026 南师大真题关联。
- 现当代文学 P0 主专题。
- 作家 / 作品证据。
- 名词解释 / 简答 / 比较 / 论述派生训练。
- 文学“今日任务”真实驱动。

仍遵守：有来源、稳定 ID、先答后看、不机械迁移旧 1101 条。

## 当前明确不做

- Android / iOS 专项适配。
- 手机软键盘、安全区、触控交互专项维护。
- 新文学专题和真题页面。
- 文学 UI 重设计。
- 排行榜、积分商城、强签到。
- 多人账号 / 权限。
- 为未来可能需求提前重构。
- 在桌面基线验收前继续新增英语训练模式。
