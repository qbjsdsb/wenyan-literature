# Wenyan 路线图

路线图只解决一件事：**下一步做什么，以及什么暂时不要做。**

当前策略：**Desktop-first + English-first**。

优先级：真实备考价值 > 数据安全 > 开始长期使用 > 开发速度 > 工程美观。

## 当前事实

Desktop English Baseline v1 已于 2026-10-06 通过 PR #11 正式合入 `main`。

英语本地核心已经具备：
- 固定考研词库与 1200 / 2444 / 5528 分层。
- 跟打 / 默写 / 听写。
- `ts-fsrs` 主动回忆调度。
- 到期 / 近期错词 / 新词智能队列。
- 收藏 / 已掌握 / 错词筛选。
- 单词详情、音标、词形、考研排名 / 词频。
- 今日新学、主动复习、到期、首次正确率、拼写错误。
- 刷新续学、旧 session 兼容、提示状态持久化。
- JSON 备份恢复。
- 根路径 / 子路径静态部署能力。

标准 CI、Chromium `dist` smoke 以及合并后的 `main` push CI 均已通过。

文学内容继续冻结。

---

## P0：固定电脑端使用入口

这是当前唯一 P0。

目标：
- 使用固定 URL / origin。
- localStorage 学习记录长期稳定积累。
- 每天打开就能学，不再依赖开发命令。
- 新版本部署不主动清学习记录。
- 出现问题可以稳定复现和回滚。

原则：
- 优先静态部署。
- 不引入业务后端。
- 不为了“像 App”先套桌面壳。
- 部署仍必须通过 `npm test`、`npm run build` 和浏览器 smoke。

---

## P1：真实连续使用

固定入口上线后，先真实使用，再继续开发。

重点观察：
- 每天打开后是否能直接开始。
- 新词数量是否合理。
- 跟打 / 默写 / 听写的真实使用比例。
- 哪些词反复错。
- 1200 核心层里多少词其实早已掌握。
- 连续训练 20—30 分钟是否出现焦点、输入延迟或状态问题。
- 备份体积和 session 日志增长速度。

真实使用反馈优先于继续猜功能。

---

## P2：快速筛词

下一个优先开发功能。

核心 1200 中会有大量本人已经认识的基础词。不要再写硬编码黑名单，而是提供快速人工判断：
- 已掌握。
- 模糊。
- 不会。

要求：
- 键盘优先。
- 一次操作成本极低。
- 直接复用现有 mastered / 学习事件边界。
- 不破坏已有 FSRS 历史。
- 可以从 1200 开始，再逐步筛 2444 / 5528。

---

## P3：真实数据驱动的调度与性能优化

只有真实使用证明有价值后再做。

### 到期排序
当前“到期优先”成立，但到期词内部还不是按逾期程度排序。若真实使用中有大量同时到期词，再改为更合理的 due 排序。

### session 日志压缩
当前 session 更新会追加完整状态事件。等长期使用证明备份 / localStorage 明显膨胀后，设计安全压缩：
- 不伤害 review 学习历史。
- 只压缩可替代的旧 session 状态。
- 保证 JSON 备份兼容。

### 长期性能
用真实长期数据 profiling `wordCounts()` / `reviewCard()`；只有确实变慢，再加派生索引或 cache。

---

## P4：可选的单人薄同步

**当前不是必做。**

只有以后出现真实多电脑切换需求时才做。

原则：
- 本机永远先保存。
- 单人使用，不建完整账号 / 权限体系。
- 优先沿用 `wenyan-events-v2` 和稳定事件 ID。
- 5528 词库本体不需要同步。
- 重复同步不产生重复事件。
- 失败不阻塞本地学习。
- JSON 备份继续保留。

如果长期只在一台电脑使用，可以一直不做同步。

---

## P5：语境强化

语境是后置强化层，不阻塞快速背词。

优先对象：
- 反复错词。
- 高频多义词。
- 孤立背会但阅读里仍认不出的词。

形式：
- 短语 / 常见搭配。
- 句子挖空 → 主动输入 → 再展示完整句。

原则：
- 不给 5528 个词批量生成低质量 AI 例句。
- 来源 / 性质可追溯。
- 不抓版权不清的词典正文。

---

## P6：考研英语能力训练

词汇长期稳定后，再把 Wenyan 从背词工具升级成考研英语训练器。

优先顺序建议：
1. 长难句。
2. 真题阅读。
3. 阅读错因体系。
4. 完形 / 翻译 / 新题型。

强调真题驱动和模块联动，不铺一个大而全题库壳。

---

## P7：恢复文学

英语稳定长期使用后再恢复：
- 2023—2026 南师大真题关联。
- 现当代文学 P0 主专题。
- 作家 / 作品证据。
- 名词解释 / 简答 / 比较 / 论述派生训练。
- 文学“今日任务”真实驱动。

仍遵守：有来源、稳定 ID、先答后看、不机械迁移旧 1101 条。

---

## 当前明确不做

- Android / iOS 专项适配。
- 手机软键盘、安全区、触控交互专项维护。
- 新文学专题和真题页面。
- 文学 UI 重设计。
- 排行榜、积分商城、强签到。
- 多人账号 / 权限。
- 为未来可能需求提前重构。
- 继续叠新英语训练模式。
