# Wenyan 路线图

路线图只解决一件事：**下一步应该做什么，以及什么暂时不要做。**

Wenyan 是单人考研工具，不按商业产品路线扩张。当前采用 **English-first**：先把英语做到可以每天稳定使用、电脑手机连续学习，再恢复文学。

优先级：真实备考价值 > 数据安全 > 开发速度 > 工程美观。

## 当前事实

英语本地功能 E1—E4 已落地：
- E1 固定考研词库与 1200 / 2444 / 5528 分层。
- E2 智能队列与近期错词闭环。
- E3 单词详情、音标与词形 enrichment。
- E4 今日新学 / 主动复习 / 到期 / 首次正确率 / 拼写错误。
- session 完整性修复：层级切换续学、未完成组保护、提示状态刷新保持。

自动测试与构建已经通过，但最新版**尚未完成真实桌面浏览器和 Android 验收**。

文学内容仍保持小样，当前冻结。

## P0：验收并收口英语本地版

当前唯一 P0。

### 1. 真实浏览器验收

以最新 session 完整性分支为对象，按 [`english/VALIDATION.md`](english/VALIDATION.md) 逐项检查：
- 核心 / 高频 / 完整词库切换。
- 跟打 / 默写 / 听写。
- 智能队列：到期 → 近期错词 → 新词。
- 单词详情、音标、词形与个人状态。
- 轻量学习统计。
- 刷新续学。
- 老 v0.1 session 兼容。
- 备份 / 导入 / undo。

发现问题分级：
- P0：数据损坏、session 丢失、评分错误、错误覆盖学习记录。
- P1：Android 键盘遮挡、TTS 不可用、明显卡顿、按钮不可达。
- P2：纯视觉微调。

P0/P1 必须在英语本地版收口前修完。

### 2. Android 真机验收

至少检查一次常用 Android 浏览器：
- 软键盘弹出后输入框仍可见。
- 提交 / 提示 / 发音按钮可触达。
- 360—430px 无横向滚动。
- 短视口可以滚到操作区。
- TTS 实际能播，失败时降级合理。
- 连续训练 30—50 词无明显输入延迟。
- 完整词库搜索 / 滚动无明显卡顿。
- 暂停、返回、刷新、重开续学自然。

桌面缩窄视口不能冒充真机验收。

### 3. 收拢 stacked PR

验收通过后停止继续叠新功能 PR。

当前历史链保留审计价值，但最终要形成一个容易继续开发的稳定基线：

```text
Web v0.1
→ 真实词库
→ 仓库维护基线
→ 英语核心
→ 详情 / enrichment
→ 学习反馈
→ session 完整性
```

目标：
- README / ROADMAP / 开发进度与真实代码一致。
- 自动测试 / 构建绿灯。
- 人工验收结果落盘。
- 再安全收拢到 `main`。

不要直接跳过验收把整串 Draft PR 一次性合入 main。

## P1：固定个人使用入口

英语本地版通过后，先让本人电脑和手机始终访问同一个稳定入口。

目的不是“正式发布产品”，而是：
- origin 不再不断变化。
- 本机学习记录能够持续积累。
- 方便跨设备同步测试。
- 后续真机问题可以稳定复现。

保持静态前端优先，不因为需要固定 URL 就引入复杂后端。

## P2：单人薄云同步

**云同步现在排在语境训练之前。**

真实需求：上班电脑背几分钟，手机继续同一进度。

原则：
- 本机永远先保存。
- 只服务一个人，不做多人账号 / 权限体系。
- 优先沿用 `wenyan-events-v2` 和稳定事件 ID。
- 同步学习事件、未完成英语 session、收藏 / 已掌握、词库层级和极少量偏好。
- 5528 词词库本体随应用版本发布，不在设备间同步。
- 冲突优先“合并不丢数据”。
- 手动 JSON 导入 / 导出继续保留为兜底。

完成标准：
- 电脑 → 手机、手机 → 电脑都能继续。
- 电脑背到 7/12，手机能继续 7/12。
- 断网学习后重新联网安全合并。
- 重复同步不产生重复事件。
- 同一条学习记录不会因设备顺序不同而出现不同 FSRS 结果。
- 同步失败明确提示，不假装成功。

## P3：真实使用后的英语微调

固定入口 + 同步完成后，先真实连续使用一段时间。

只修高频痛点，例如：
- 电脑真正有用的快捷键。
- 手机单手操作。
- 默认新词量。
- 发音速度 / 自动发音偏好。
- 哪些统计值得保留。

不要在没有真实痛点前堆设置页。

## P4：语境强化

语境是后置强化层，不阻塞快速背词。

优先对象：
- 反复错词。
- 高频多义词。
- 孤立背会但阅读里仍认不出的词。

形式：
- 短语 / 常见搭配。
- 句子挖空 → 主动输入 → 再展示完整句。

原则：
- 不给 5528 个词批量生成一堆低质量 AI 例句。
- 例句来源 / 性质可追溯。
- 可自行编写，但关键语义需核验。
- 不抓付费词典或版权不清内容。

## P5：恢复文学

只有英语已经稳定长期使用后再恢复：
- 2023—2026 南师大真题关联。
- 现当代文学 P0 主专题。
- 作家 / 作品证据。
- 名词解释 / 简答 / 比较 / 论述派生训练。
- 文学“今日任务”真实驱动。

仍遵守：有来源、稳定 ID、先答后看、不机械迁移旧 1101 条。

## 暂时不做

当前默认不做：
- 新文学专题和真题页面。
- 文学 UI 重设计。
- 排行榜、积分商城、强签到。
- 多人账号 / 权限。
- 为未来可能需求提前重构。
- 在真机验收前继续新增英语训练模式。
