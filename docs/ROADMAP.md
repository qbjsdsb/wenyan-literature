# Wenyan 路线图

路线图只解决一件事：**下一步应该做什么，以及什么暂时不要做。**

Wenyan 是单人考研工具，不按商业产品路线扩张。优先级始终是：真实备考价值 > 数据安全 > 开发速度 > 工程美观。

## 当前基线

- Web v0.1 已形成可运行的本地优先学习闭环。
- 英语词汇正在从 24 个样本词升级到真实考研词频词库。
- 文学内容仍以小样为主，尚未完成 P0 主干专题与真题关联。
- 自动云同步尚未接入。

## P0：先变成“每天真的能用”

### 1. 验收英语词汇 v1

完成标准：
- `npm test` 通过。
- `npm run build` 通过。
- 首次联网能加载考研词库。
- 缓存后二次打开可继续使用。
- 断网时有缓存继续用、无缓存退回内置词组。
- 旧 v0.1 未完成词组、收藏与复习记录仍可继续。
- Android 真机至少检查一次输入法、长列表、发音和短视口。

### 2. 接入现当代文学 P0 内容

优先顺序：
1. 2023—2026 真题实际触达专题。
2. 高频现代作家、当代作家与关键文学现象。
3. 作品证据与可用于论述的例子。
4. 从同一事实源派生名词解释、简答、比较、论述练习。

完成标准：
- 每个专题有明确来源。
- 题目先答后看，不直接展示完整答案。
- 真题与知识专题能互相跳转。
- 不机械迁移旧 Android 1101 条知识点。

### 3. 让“今日”真正可用

完成标准：
- 今日任务来自真实到期复习、未完成训练和当前 P0 学习计划。
- 不为了统计增加额外操作。
- 电脑可以快速键盘启动，手机可以连续触控完成。

## P1：单人薄云同步

目标：电脑学完，手机打开能接着学。

原则：
- 本机永远先保存。
- 只同步学习状态，不建立复杂账号体系。
- 继续使用稳定事件 ID 和当前 schema，除非有明确迁移方案。
- 冲突处理优先“合并不丢数据”，失败必须明确提示。
- 先验证一个人的两台设备，不做多人协作。

完成标准：
- 电脑 → 手机与手机 → 电脑都能续学。
- 断网学习后恢复联网可安全合并。
- 重复同步不制造重复记录。
- 手动导入/导出仍保留作为兜底。

## P2：真实使用后的优化

只根据连续使用中出现的真实卡点做：
- 快捷键。
- 训练节奏。
- 复习间隔体验。
- 阅读排版。
- 词库分层和搜索。
- 真题答题空间。
- 手机键盘与安全区。

没有真实痛点，不做大改版。

## 暂时不做

除非真实需求改变，否则不进入近期计划：
- 商业化、多用户、班级、教师后台。
- React / Vue 重构。
- 独立 Node 业务后端。
- 微服务、ORM、复杂权限系统。
- CRDT、实时协作、通用知识图谱基础设施。
- 为了“完整”一次性迁移全部旧知识点。
- 大量 AI 生成内容未经来源核验直接进入正式学习库。

## 每次迭代的 Definition of Done

一项功能只有同时满足以下条件才算完成：

1. 用户能实际使用，而不只是代码存在。
2. 不破坏已有学习记录；若数据格式变化，有明确迁移或兼容方案。
3. 该跑的测试和构建已跑，并记录实际结果。
4. 页面功能至少做一次真实浏览器检查；涉及手机特性时不能用缩窄桌面窗口冒充真机。
5. 内容有来源，第三方资产有许可证记录。
6. `docs/开发进度.md` 已更新到真实远端状态。
7. PR 保持边界清楚，不把无关重构顺手混进去。
