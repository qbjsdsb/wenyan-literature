## 一、关于"小红书能不能看"的实测结论（重要）

**结论：当前环境无法抓取小红书站内笔记原文，原因是 IP 风控，非技术手段可绕过。**

### 实测过程

| 步骤 | 方法 | 结果 |
|---|---|---|
| 1. curl 抓搜索页 HTML | `curl -sL xiaohongshu.com/search_result?keyword=...` | ✅ HTTP 200，792KB，但 SSR 的 `search.feeds` 为空数组（笔记靠 JS 异步加载）|
| 2. 解析 SSR 数据 | 提取 `window.__INITIAL_STATE__` | ✅ 拿到 `searchContext`（keyword/pageSize=20），但 `feeds` 空 |
| 3. 安装 chromium 执行 JS | 手动 wget chrome 152 + apt 装依赖 | ✅ Chrome 152.0.7936.0 启动成功 |
| 4. agent-browser 打开搜索页 | `--executable-path` 指定 chrome | ❌ 被重定向到 `website-login/error?error_code=300012&error_msg=IP at risk. Switch to a secure network and retry.` |
| 5. 移动端 UA 测试 | iPhone UA | ❌ 返回"页面不见了" |

### 风控根因

- 小红书对**云服务器/数据中心 IP**严格风控，error_code=300012 表示"IP 有风险，请切换到安全网络"
- 当前是远程沙箱环境（CI=true），IP 属于数据中心段，被标记为风险 IP
- **这是 IP 层面的硬限制**，换 UA、加 cookie、用浏览器执行 JS 都无法绕过
- 唯一解法：用家庭/移动宽带 IP 访问（即在你自己电脑上抓）

### 给你的建议

如果你想看小红书原文，**在你自己电脑上操作最简单**：
1. 直接用浏览器打开 `https://www.xiaohongshu.com/search_result?keyword=南师大现当代文学考研`
2. 搜索结果里会有很多上岸学姐的笔记，重点看：上岸经验、610/801 真题回忆、复习时间表
3. 关键词推荐：`南师大现当代文学考研`、`南师大610文学基础`、`南师大801专业写作`、`南师大现当代上岸`

### 4. 南师命题偏好（在读研究生提醒）

- **古代文学**：南师现题型**只有论述题**，但简答论述都要准备。喜欢考**对比题**（如王维孟浩然 vs 高适岑参）和**版本题**（如《三国志演义》《西游记》成书过程）
- **古代文学**：二流作家（鲍照、庾信、张先、吴文英）可选择性跳过
- **文学理论**：考过**以章节题目做简答题**的题目，**目录小标题要重视**（如"文学接受的高潮"→ 答案是"共鸣、净化、领悟、余味"）
- **外国文学**：**只考西方文学**，东方文学（日本、印度、非洲、阿拉伯）基本不考，略微浏览即可
- **答题规范**：南师注重"**论点+论据**"，论据必须是原著，引用原典（如刘勰《文心雕龙》、钟嵘《诗品》）更显专业
