# 文研内容源目录 v1

> 建立日期：2026-09-29  
> 用途：给新版 `wenyan-literature` 提供“知识体系骨架与核验入口”，不是把公开课讲义整段复制进仓库。

## 原则

1. **官方/高校公开课程负责定骨架**：确定哪些时代、作家、作品、概念值得进入知识树。
2. **教材与原典负责核事实**：具体表述、例证、引文优先回到可靠教材/原典。
3. **南师大历年真题负责定优先级**：真题触达、高频、可形成输出训练的知识优先整理。
4. **AI 只做编辑，不做来源**：可压缩、重组、生成回忆提示，但不能把“AI 说过”当证据。
5. **公开可读 ≠ 可整段转载**：课程页面用于目录/书目/事实核验；不批量复制视频字幕、课件、讲义。

## C 级：原典与学术补强

### 中文原典

- 维基文库：https://zh.wikisource.org/
- 中国哲学书电子化计划：https://ctext.org/zhs

用途：核作品原文、经典篇章、古代文论出处。入库前仍要确认具体文本版本和版权状态。

### 外文公共领域原典

- Project Gutenberg：https://www.gutenberg.org/

用途：核外国文学经典原文。公开 GitHub 若要收录全文/长段，需另外确认中国法域下的版权状态；默认只做链接和短引核验。

### 学术论文

- 国家哲学社会科学文献中心：https://www.ncpssd.cn/

用途：给论述题补“学术观点/研究问题/争议”，不用于代替文学史基础知识。

## D 级：真题与经验材料

- Android 仓库当前真题基线：`wenyan-android/app/src/main/assets/seed_data.json`

- 前端仓库已有：`docs/南师大现当代文学考研-二轮调研报告.md`

这些材料价值很高，但来源等级不一：
- 原始试卷 / 官方公开材料：高可信；
- 可复核公开回忆题：保留并标注“回忆”；
- 经验贴：只用于学习策略、命题倾向线索，不能当作考试事实或教材结论。

## 新版文研内容入库最低要求

一个“核心知识点”理想上至少拥有：

- `title`：稳定标题；
- `subject` / `topic`：明确归属；
- `core`：30 秒可回忆的核心结论；
- `outline`：答题骨架；
- `examples`：作品/原典证据；
- `source`：可追到教材、公开课章节或原典；
- `questionIds`：若有南师真题触达则关联；
- `priority`：由真题、高频和复习价值决定，而不是内容篇幅决定。

第一版不要求每条都有论文级出处，但 **HIGH + 真题触达** 的知识点必须优先补来源。
