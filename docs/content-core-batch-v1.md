# 新文研 · 第一批核心内容清单 v1

> 目标：不是“把 1101 条迁过去”，而是先做一批真正能背、能答、能和真题连起来的核心专题。  
> 规模：约 50 个主专题。每个主专题可派生多个回忆提示，但只维护一份核心事实与来源。

## 选取规则

优先级按下面顺序：
1. 2023—2026 真题直接触达；
2. Android 标记 HIGH；
3. 南师大/高校公开课程主干；
4. 当前来源缺失，补证据后收益很高；
5. 能同时服务名词解释、简答、论述，而不是纯百科细节。

每个专题整理成：
- 30 秒核心结论；
- 4—6 个答题分点；
- 2—4 个作品/原典例证；
- 1 个可靠来源；
- 关联真题；
- 2—5 个回忆问题。

## 第一批真题关联

先只做 2023—2026 的 79 道题：

1. 用标题/tags/实体做候选匹配；
2. 人工确认每道题 1—5 个核心知识点；
3. 不为了“覆盖率”硬连无关知识；
4. 论述题可以关联“比较型专题”，不必只绑单个作家；
5. 真题作答后，把遗漏分点映射回这些知识点。

这一步完成后，新版才能真正实现：

**真题 → 漏点 → 知识复习 → 再答真题**
