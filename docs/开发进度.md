## 4. 最新 P0：session 完整性修复

云端代码复核后确认三个真实风险；已从 PR #8 最新 head 开出：

`feature/english-session-integrity-v1`

最终验证提交：`1e2426f69ba16a1a8bdb0ea9eb47c6aea6d4ca4f`。

修复内容：

### A. 词库层切换 / 异步加载不再破坏续学
- 未完成 session 的剩余词 ID 会临时保留在活动词表。
- 即使从完整层切回核心层，当前组里的低频词仍能完成。
- 直接恢复 `#train` 时，如果正式词库还在异步加载，不再把 session 清空；先保留记录等待加载。
- 正式词库载入后训练页自动重新渲染。
- 如果最终仍无法解析当前词，显示明确错误，但不删除 session。

### B. “智能开始”不再覆盖未完成组
- 有未完成英语 session 时，英语页主按钮直接显示“继续上次”。
- `startWords()` 也有二次保护；即使被其他入口调用，也不会新建 session 覆盖旧组。

### C. 提示状态立即持久化
- 点击“提示”立即把 `hinted:true` 写入 session。
- 默写模式训练中主动播放单词发音，也立即记录为提示。
- 在尚未提交答案前刷新，提示状态仍保留。
- 第一次提交再记录 `firstCorrect` 时，会保留之前已经写入的 `hinted:true`，不会被覆盖。

### D. 新增测试
- 未完成 session 的待学词提取。
- 提示状态持久化但不提前伪造 `firstCorrect`。
- 刷新后第一次提交仍保留已用提示。
- 首次正确/错误结果不可被后续尝试覆盖。
- 切换到较小词库层时仍保留当前 session 的低频词。

## 7. 验收后的正式顺序

1. 修复验收发现的 P0 / P1。
2. 收拢 PR #2—#8 + session 修复，形成可靠 `main` 基线。
3. 提供固定个人使用入口，避免 origin 反复变化。
4. 做单人薄云同步：本机先写，电脑 ↔ 手机同步事件、session 和少量偏好。
5. 真实连续使用一段，只修高频卡点。
6. 再做高频难词 / 反复错词语境强化。
7. 最后恢复文学。

## 8. 稳定数据边界

不要随意破坏：
- `wenyan-events-v2`。
- 稳定事件 ID。
- `word:<规范化英文单词>`。
- 收藏 / 已掌握事件语义。
- 英语未完成 session。
- 首次正确 / 错误 / hinted 结果。
- JSON 备份兼容。
- `ts-fsrs` 历史。

词库与 enrichment 属于版本化内容数据，不属于用户学习状态。
