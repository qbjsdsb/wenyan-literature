## 1. 当前产品基线

Wenyan 已从旧版文学知识 Demo 转向：

**单人使用的南京师范大学文学考研工具，Web 优先，本地优先，电脑和手机都能快速继续学习。**

当前可运行基线是 Web v0.1：

- 今日 / 知识 / 训练三个一级入口。
- 文学阅读、回忆练习、英语训练闭环。
- localStorage 本机保存。
- 阅读位置、未完成英语 session、未完成文学回忆可续接。
- JSON 导入 / 导出备份。
- `ts-fsrs` 复习调度。
- 旧版资料保留在 `legacy/`。

文学正式内容仍未完成，当前只是小样；英语真实词库升级正在单独 PR 验收。

## 3. 已确认的 Web v0.1 验收

详细记录：[`web-v0.1-validation.md`](web-v0.1-validation.md)。

已确认：

- 阅读第 1 节 → 第 2 节 → 刷新后可继续。
- 文学回忆先自己想，再看提纲，自评后记录复习。
- 英语首次答错 → 完整订正 → 刷新续学 → 首次错误仍保留。
- JSON 文字备份和文件导入可合并恢复。
- 多标签写入前合并，不静默覆盖另一标签记录。
- 损坏记录不覆盖原数据。
- 主要桌面 / 手机宽度没有横向溢出。

明确未冒充通过：

- Android 真实系统键盘。
- 英文语音在真机上的表现。
- 真机安全区。
- 下载文件最终落地行为。
- 自动云同步。

## 7. 仓库维护规则

- `docs/开发进度.md`：只维护当前真实状态。
- `docs/ROADMAP.md`：只维护未来优先级和完成标准。
- `docs/ARCHITECTURE.md`：只维护稳定边界。
- `docs/README.md`：文档导航。
- `.github/pull_request_template.md`：每个新 PR 的最小检查清单。
- 研究材料是输入，不自动等于产品事实。
- 验收文档只写实际做过的验证。
- PR / commit 已经存在的历史，不在这里重复堆流水账。
