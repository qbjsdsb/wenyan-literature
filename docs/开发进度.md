# Wenyan 当前开发状态

> **这是仓库唯一“当前状态”事实源。**
>
> 更新日期：2026-10-06。任何后续 AI / Work 接手时，先核对 GitHub 实际分支与 PR；如果远端状态与本文件冲突，以远端为准并立即修正本文件。

## 1. 当前产品基线

Wenyan 已从旧版文学知识 Demo 转向：

**单人使用的南京师范大学文学考研工具，Web 优先，本地优先，电脑和手机都能快速继续学习。**

当前可运行基线是 Web v0.1：

- 今日 / 知识 / 训练三个一级入口。
- 文学阅读、回忆练习、英语训练闭环。
- localStorage 本机保存。
- 阅读位置、未完成英语 session、未完成文学回忆可续接。
- JSON 导入 / 导出备份。
- `ts-fsrs` 复习调度。
- 旧版资料保留在 `legacy/`。

### 当前开发策略：English-first

用户已明确：**先把英语部分做好，文学与其他内容暂时后置。**

因此当前：
- 英语是唯一 P0 产品线。
- 文学正式内容仍停留在小样阶段，暂不扩充。
- 2023—2026 文学真题关联暂缓。
- 文学“今日任务”暂不继续深化。
- 英语本地版稳定后，优先做服务英语的单人薄云同步；不必等待文学内容完成。

总路线见 [`ROADMAP.md`](ROADMAP.md)，英语专项见 [`english/PLAN.md`](english/PLAN.md)。

## 5. 当前最优先的下一动作

按 [`english/PLAN.md`](english/PLAN.md) 执行。

### E0：验收英语词汇 v1

顺序：
1. `npm test`
2. `npm run build`
3. 首次联网加载 5530 目录并进入训练
4. 刷新检查缓存
5. 断网有缓存 / 无缓存两种情况
6. 旧 v0.1 未完成英语 session 兼容
7. Android 真机长列表、键盘、发音、短视口

通过后把 PR #3 变成可信英语基线。

### E1：固定词库快照与学习分层

当前运行时读取远程 `master` 只适合作为第一版验证方案。下一阶段建议：

- 固定 NETEMVocabulary 明确 release / commit。
- 生成 Wenyan 自己的规范化静态快照。
- 首次正式使用不依赖第三方 CDN。
- 新词范围分成前 1200 核心、前 2444 高频、完整 5530。
- 切换范围只改变新词池，不改变旧复习记录。
- 长词表使用搜索 / 筛选 / 分段显示，不一次渲染 5530 DOM 行。

### E2：智能队列与错词闭环

默认开始学习直接按：

`到期复习 → 近期错词 → 未完成组 → 当日新词`

并补齐：
- 自动错词本。
- 一键重练错词。
- 新词额度。
- 跟打 / 默写 / 听写职责区分。
- 主动回忆才影响长期 FSRS；跟打不伪装成“记住了”。

### E3：词条信息质量

补：
- 音标。
- 词性。
- 核心高频义。
- 常见变形 / 异形。
- 英 / 美发音能力或可靠 TTS 降级。

### E4：长期使用反馈

补：
- 今日新学。
- 今日复习。
- 到期量。
- 首次正确率。
- 拼写错误数。
- 跟打速度 / 正确率（轻量）。

不做排行榜、积分商城、重度游戏化。

### E5：语境强化

孤立词训练稳定以后，再为高频难词 / 反复错词增加短语和句子挖空输入。语境模式后置，不阻塞快速背词主流程。

### E6：英语真机收口 + 薄云同步

英语本地体验稳定后，直接进入电脑 ↔ 手机同步；同步优先服务英语学习状态，不等文学完成。
