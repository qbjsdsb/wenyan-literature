## 当前策略

**Desktop-first + English-first**

- 先把电脑端英语做成每天稳定使用的个人工具。
- 文学正式内容继续冻结。
- 当前不维护 Android / iOS 专项体验。
- 云同步不是近期必做；只有出现真实多电脑需求时再做。
- 当前不继续堆训练功能，先收拢可靠 `main` 并建立固定桌面入口。

## 已完成的英语能力

### 词库
- 固定 NETEMVocabulary 版本。
- 上游 5530 行 → **5528 个稳定学习 ID**。
- 核心 1200 / 高频 2444 / 完整 5528。
- 正常运行使用随应用发布的本地快照。
- 词库内容与学习状态分离。
- `may/May`、`march/March` 等规范化重复项合并义项，不静默丢数据。
- 兼容旧 v0.1 词与正式层级规模分开计数。
- 未完成 session 临时保留的低频词单独作为 `carryover`，不污染层级规模。

### 训练
- 跟打 / 默写 / 听写。
- 首次拼错保留，必须完整订正。
- `ts-fsrs` 只用于主动回忆调度。
- 默认智能队列：`到期 → 近期错词 → 新词`。
- 收藏 / 已掌握 / 错词筛选。
- undo。

### Session 稳定性
- 刷新后续学。
- 词库异步加载时不清空 session。
- 切换词库层不丢当前组低频词。
- 有未完成组时不能被“智能开始”覆盖。
- 点击提示立即保存 `hinted:true`。
- 刷新后 hinted 和首次答题结果仍可靠。
- 旧 v0.1 种子词继续兼容。

### 单词详情
- 中文义。
- 考研排名 / 词频。
- 分类 / 子分类 / 变体。
- 当前学习状态。
- 近期错词 / 收藏。
- 复习次数与下次复习信息。
- 固定 ECDICT enrichment：5528 目标词中匹配 5519，音标 5509，词形变化 4621。
- 固定版本没有可靠词性覆盖，因此不展示假词性。

### 学习反馈
- 今日新学。
- 主动复习。
- 当前到期。
- 首次正确率。
- 拼写错误。

全部从 `wenyan-events-v2` 派生，不维护第二套统计数据库。

### 备份
- JSON 导出 / 导入。
- 学习事件、收藏、已掌握和未完成 session 可恢复。
- 浏览器 smoke 已真实验证“导出 → 新 browser context 导入 → 继续未完成训练”，不是只测 JSON 解析。

## 当前 merge gate

PR #11 已经达到工程上的合并门槛。当前只要求：
1. 本轮验收记录写入后，最终 head 的标准 CI 再绿一次。
2. 最终 head 的 `desktop-browser-smoke` 再绿一次。
3. 若无新的 P0 / P1，则 PR #11 合入 `main`。

**本人 Windows 连续使用几天、TTS 真实扬声器体验、主观键盘手感不再作为无限阻塞 main 的条件。** 它们属于固定入口上线后的真实使用反馈。

## 合入 main 后的顺序

1. 关闭已被 #11 取代的 PR #2—#10，保留历史但避免误接。
2. 提供固定电脑端访问入口。
3. 本人开始连续真实使用。
4. 下一个优先开发功能：**快速筛词**，而不是继续堆词典信息或训练模式。
5. 再根据真实数据决定：到期排序、session 日志压缩、长期性能优化。
6. 只有出现真实多电脑需求时才做薄同步。
7. 再做高频难词 / 反复错词语境强化。
8. 最后恢复文学。
