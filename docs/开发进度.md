## 1. 当前策略：English-first

用户已明确：**先把英语部分做好，文学与其他内容暂时后置。**

当前规则：
- 英语是唯一 P0 产品线。
- 文学正式内容维持现有小样，不扩充。
- 2023—2026 文学真题关联暂缓。
- 英语本地版通过真实浏览器 / Android 验收后，再进入语境强化与单人薄云同步。

英语专项见 [`english/PLAN.md`](english/PLAN.md)。

## 3. 已实现的英语本地能力

### E1：固定词库与分层

- NETEMVocabulary 固定到 `bf83111e0ebf29c6f9aca45d2a4f30e2c72af2e7`。
- 上游 5530 行规范化为 **5528 个唯一词条**；重复规范化 ID：`march`、`may`。
- 随应用发布本地固定快照；正常使用不再跟随远程 `master`。
- 三层范围：核心 1200 / 高频 2444 / 完整 5528 唯一词。
- 旧 24 种子词保留，保护旧收藏、FSRS 记录和未完成 session。
- 词库内容与 `wenyan-events-v2` 学习状态分离。

### E2：智能队列与错词

默认：

`到期复习 → 近期错词 → 新词`

- 错词从现有 `review` / `typing` 事件派生。
- 忘记、首次拼错、使用提示可进入近期错词。
- 后续正确可清除旧错词派生状态。
- undo 生效。
- 英语页有“错词”筛选。
- 长词表限制 DOM 渲染量，完整词库不会一次渲染 5528 行。

### E3-A：详情信息

详情页已经能展示：
- 学习状态：新词 / 到期 / 复习中 / 已掌握。
- 近期错词 / 收藏。

- 分类 / 子分类。
- 其他拼写 / 变体。
- 主动复习次数与下次复习状态。

### E4：轻量学习反馈

英语页已经增加：
- 今日新学。
- 主动复习。
- 当前到期。
- 首次正确率。
- 拼写错误。

统计规则：
- 跟打不算主动复习，也不进入首次正确率。
- “今日新学”只看第一次主动 `review` 是否发生在今天。
- 首次正确率只把未提示、首次拼写正确且评分不是忘记的主动回忆算成功。
- 拼写错误覆盖三种模式的首次拼错，但每个已记录训练结果只计一次。
- undo 自动从统计中消失。

## 4. 自动验证

仓库 CI：

```text
Node 24 → npm ci → npm test → npm run build
```

E1—E4 的业务应用都采用“先修改 → 自动测试 → 自动构建 → 成功后才提交”的方式。

已出现并处理过两次真实保护案例：
1. 词库生成 workflow 最初没有识别未跟踪生成文件，修复后才真正提交快照。
2. E4 首次测试把昨天的复习误写成今日统计期望，CI 中止提交；修正后测试和构建通过才落业务代码。

因此不能把“代码写出来”当成完成，当前自动层面已经有可复现保护。

## 6. 稳定数据边界

不要随意破坏：
- `wenyan-events-v2`。
- 稳定事件 ID。
- `word:<规范化英文单词>`。
- 收藏 / 已掌握事件语义。
- 英语未完成 session。
- 首次正确 / 错误结果。
- JSON 备份兼容。
- 现有 `ts-fsrs` 历史。

词库和 enrichment 属于版本化内容数据，不属于用户学习状态。

## 7. 验收后的顺序

1. 修复真实浏览器 / Android 验收发现的问题。
2. 根据实际背词体验决定是否补极少量桌面快捷键 / 手机细节。
3. E5 语境强化：只做高频难词 / 反复错词，不给 5528 词批量塞例句。
4. E6 单人薄云同步：电脑 ↔ 手机同步学习事件和少量英语偏好，词库本体不同步。
5. 英语连续使用稳定后，再恢复文学开发。
