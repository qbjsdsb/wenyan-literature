## 1. 当前策略：English-first

用户已明确：**先把英语部分做好，文学与其他内容暂时后置。**

因此当前：
- 英语是唯一 P0 产品线。
- 文学正式内容停留在现有小样，不扩充。
- 2023—2026 文学真题关联暂缓。
- 英语本地体验稳定后，优先做服务英语的单人薄云同步；不等待文学完成。

英语专项见 [`english/PLAN.md`](english/PLAN.md)，总路线见 [`ROADMAP.md`](ROADMAP.md)。

- 稳定事件 ID。
- `word:<规范化英文单词>` 键规则。

词库本体属于内容数据，不属于用户学习状态。详细边界见 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

## 6. 当前下一动作

### E3：单词详情与信息质量

先使用 PR #5 已经拥有的数据，不急着引入新的外部词典：
- 排名 / 词频。
- 分类 / 子分类。
- 其他拼写 / 变体。
- 当前状态：新词 / 到期 / 下次复习。
- 收藏 / 已掌握 / 发音。

然后单独审核音标、词性数据源的许可证和质量，再决定是否接入。

### E4：长期使用反馈

E3 稳定后补：今日新学、今日复习、首次正确率、拼写错误数、到期量，以及桌面快捷键 / 手机训练细节。

### E5：语境强化

只面向高频难词和反复错词，后置，不阻塞快速背词。

### E6：真机收口 + 单人薄云同步

本地英语体验稳定后做电脑 ↔ 手机连续学习；词库本体随应用版本发布，只同步学习事件和少量偏好。
